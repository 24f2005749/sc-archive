## System Commands

- `mkdir` -> used to create a folder (`-p` flag makes the parent if required)

- `echo` -> used to print something, somewhere (`>,>>,<,<<` are used to tell where to print/send)

- `touch` -> used to create a file

- `{}` -> used to pass a number of things, called brace expansion. Usage: {1..100} or {1,2,3}

- `chmod` -> used to change permissions of a file (1: x, 2: w, 4:r)

- `ln` -> used to link files (`-s` flag makes it a symbolic link). Usage: ln -s target link_name (link_name doesnt necessarily have to be a filename it can be the destination folder also)
